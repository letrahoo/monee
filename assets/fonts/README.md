# 中文显示字体

`noto_sans_sc.ttf` 是 Noto Sans SC 可变字体，用于 KMP Web / Mac 体验验证中的中文显示，不代表最终品牌字体选型。

- 来源：[Google Fonts / Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc)
- 原文件：`NotoSansSC[wght].ttf`，本地仅重命名，未修改字体内容。
- 许可证：[SIL Open Font License 1.1](OFL.txt)，随应用资源一同分发。
- 下载日期：2026-09-14。

首轮使用完整字体以支持任意中文搜索输入；后续可验证字体子集和按需加载，衡量 Web 首次加载成本与离线可用性。
