# MAC-INPUT-01：Mac 自动输入间歇失效

状态：未解决，2026-09-20 经用户决定单独记录、延后专项排查；继续不受影响的 Web/后端工作，不再反复要求用户代填或切换输入法。实际未验收项仍保留，不以此记录替代合并门槛。

## 已证实的现象

- Mac 人工输入并保存合成转账成功，Agent 刷新及重进账本复核一致；不是所有输入或保存失效。
- 自动点击/读取通常有效，但文字注入可能不改变字段，粘贴可能等待应用读取剪贴板超时；搜索框与转账表单均复现过。
- 同一运行包也有自动文字、粘贴及快捷键删除全部成功的轮次。用户将 App 置于前台后成功，随后又失败；成功轮次 AX 报告 focused element，失败轮次常无该报告。仅为关联，不证明根因。
- 英文/中文条件下均观察过文字成功；切英文、重启 GPT、重建工具绑定、Raise 或标题栏点击没有稳定消除问题。
- Web 自动输入/粘贴/删除及搜索已实际通过，没有复现同类持续失败。

## 当前代码与边界

- `0e577d4` 处理 CA 配置读取阻塞 EDT，与自动输入根因分开；六项 CI 成功。
- 当前包还有工作区的 Dock 图标补丁；临时输入监听已移除。未改系统键盘映射、输入法、控制权限或认证。
- 独立只读审查未发现表单按键拦截或字段状态周期重置；不能把未定位问题归因用户占用输入法。

## 后续专项验证

仅用纯合成、非敏感字段，现场比较 AWT 窗口 active/focused、KEY_PRESSED/TYPED/RELEASED 和 IME 提交计数、Compose 字段焦点及 onValueChange 计数。不记录字符、键值、剪贴板、账号或账目内容。分别验证前台/后台及人工/自动输入，定位后进行最小修复与独立审查。不得靠强制持续抢焦点、权限放宽或认证绕过完成验收。
