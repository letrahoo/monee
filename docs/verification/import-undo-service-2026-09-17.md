## 分工和范围

三个代理分别负责撤销/恢复后端、本地服务实例标识与锁验证、Mac 启动与打包。主代理负责共享 UI、导入状态、接口集成、实际两端验收和交付。各代理不独立提交或操作个人账本；所有金融测试只使用隔离合成数据，无云端模型调用。

M-07 使用当前服务端账本版本生成撤销/恢复预览；只撤销本批新增且未被修改/其他批次引用的交易。保留来源、原始文件与分录，软删除更新版本及审计。恢复保持原交易 ID，只恢复本批仍拥有且版本匹配的删除标记；任一自有记录变化则整批返回 409。历史独立显示 undone，不把原导入回执改写成零。重复导入不会使撤销记录复活。

M-37 将 Go 与 Web 产物打入 Mac；读取目录内原子写入的 discovery 并与健康接口核对随机实例 ID/协议。启动锁串行化桌面启动，Go 生命周期锁禁止同一数据目录的第二个进程。无法识别或身份不匹配的已有服务不会被自动杀掉。关闭桌面不会终止共享 Go 服务。

## 自动检查

- Go 全量 race 与 vet 通过；包括撤销/恢复总额与版本、幂等重复、恢复冲突原子性、并发、只读/成员撤销/跨账本授权、手工/修订/共享记录保护、同文件及不同字节重导不复活、来源与分录保留、历史及预览 undone 标记。
- 进程发现测试覆盖原子写入、0600 权限、256-bit 实例 ID、失败清理、跨进程锁拒绝/退出释放/异常死亡释放。
- 桌面 7 项状态机/解析测试覆盖复用、启动、未知/身份不匹配服务拒绝、超时重试、取消，以及非法 URL/旧版/损坏/超大 discovery。
- 共享契约测试覆盖撤销状态与原回执并存、保留行与影响金额区分、部分恢复冲突 blockedCount。
- 实机启动发现 jpackage 把 Go 程序复制为 0644，已在构建签名前恢复执行权限并签名内置服务及 App。不能只凭打包成功判定能运行。
- 独立复核发现部分恢复冲突时 UI 仍显示可确认，已新增 blockedCount，显示整批无法恢复并禁用确认；服务端继续原子拒绝。
