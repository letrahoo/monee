## 实际双端验证

独立测试账本 QA CSV 0917；正式 letra 账本未试写。既有 QA Import 0917 仅用于查看原生 XLSX 脱敏预览。

1. Web 新建测试账本：0 笔、收入支出 0；通过文件选择器导入仓库 ordinary-and-review.csv，预览新增 1 笔 12.34、3 条待核实（退款/转账/1.001），物理行号正确。
2. Web 确认前查看脱敏预览：3 条可用、1 条金额排除；字段展开显示整数分 1234、日期到日和 HMAC 引用。账本仍为 0 笔、0 金额。确认后为 1 笔、支出 12.34、收入 0。
3. Mac 实际原生文件选择器选择同一 CSV，提示已入账，不显示再次确认入口；读到同样 1 笔及金额。打开 CSV 脱敏字段，与 Web 同批次所有引用一致。
4. Web 同账户导入对应 XLSX，预览与确认均新增 0、跳过 1；最终仍为 1 笔、支出 12.34、收入 0。
5. Web 仅导入金额 1.001 的合成行，脱敏结果可用 0、排除 1，显示没有有效记录，未取整；账本不变。
6. Web 导入正常首行加损坏尾行的合成 CSV：第 4 行列数错误，保留失败批次，无脱敏入口。Mac 打开同批次显示错误且确认按钮禁用；首行未部分入账。
7. Mac 读取既有 XLSX 脱敏预览：3 条可用、1 条排除，展开字段通过；投影为来源原值，未读取之后的账单更正。
