# Monee 0.0.1

首个 GitHub 构建预览版，支持 Web 与 Mac。

## 下载与运行

- Apple Silicon Mac 选择 `macos-arm64.tar.gz`；Intel Mac 选择 `macos-amd64.tar.gz`。
- Linux x64 选择 `linux-amd64.tar.gz`，通过浏览器使用。
- 完整压缩包包含本地服务、Web、配置工具，以及 Mac 包中的 Monee.app；DMG 仅包含桌面客户端，仍需压缩包内的本地服务。
- 解压后，在解压目录运行 `python3 configure-login.py` 配置自己的 Google/GitHub OAuth 与初始超管，再运行 `./start.command`，保持服务运行。配置需要 Python 3；运行预编译服务无需 Go，Mac App 已附带 Java 运行时。
- 浏览器打开 http://127.0.0.1:4173/；Mac 可同时打开 Monee.app。二者共用本地账本。
- OAuth 回调为 `http://127.0.0.1:4173/auth/callback/github` 或 `http://127.0.0.1:4173/auth/callback/google`。具体配置见仓库登录指南。

## 已有功能

标准 UTF-8 CSV 预览与确认导入、重复检查、手动人民币收入/支出、月度统计、搜索、分页、Google/GitHub 登录及白名单。

## 预览版限制

Mac 包尚未签名或公证，系统可能阻止直接打开；尚未实现本地服务自动启动。OAuth 凭据由使用者单独配置，下载包不含个人凭据或账本。未配置登录时不能访问数据。

尚不支持银行/支付平台原生账单格式、退款/还款/转账、云同步、iOS 或 Android。真实 OAuth 登录与桌面交互不属于 CI 自动验证范围。

发布版本为 0.0.1；Mac 内部构建号独立使用 1.0.1。每个下载包附带 SHA-256 校验文件。
